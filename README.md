# 🛍️ AI Bazaar – Frontend

AI Bazaar is a web-based platform designed to help small shopkeepers manage sales and inventory with AI-driven insights and an intuitive dashboard.

## 🚀 Live Demo
https://ai-bazaar-frontend.vercel.app

## 📌 Features
- User authentication (login system)
- Interactive dashboard with analytics
- Integration with backend APIs
- Real-time data display

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
